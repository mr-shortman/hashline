# M3 — Linux-Auslieferung und Abschlussprüfung

Stand: 9. September 2026. Ziel: Ubuntu 26.04 LTS, amd64.

Die native Paketierung ersetzt den historischen Tauri-Bundle-Schritt.
`packaging/build_deb.py` baut das
Release-Binary und installiert Desktop-Eintrag, MIME-Definition, GSettings-XML,
SVG- und PNG-Icons, Handbuch und Dokumentation in ein `.deb`. Laufzeitabhängigkeiten
kommen aus `dpkg-shlibdeps`; gemeinsame Desktop-Caches verwalten die
Distributionstrigger. Es wird keine Standardanwendung gesetzt.

## Nachweise

| Prüfung | Ergebnis |
| --- | --- |
| `cargo fmt --all --check` | bestanden |
| `cargo clippy --locked --workspace --all-targets -- -D warnings` | bestanden |
| `GSETTINGS_BACKEND=memory cargo test --locked --workspace` | 80 bestanden; ein separater GTK-Integrationstest bleibt standardmäßig ignoriert |
| Release-Build | bestanden |
| Desktop-Datei, MIME-XML und GSettings-Schema | beim Paketbau validiert |
| Installierter Paketinhalt | ca. 3,83 MiB; Ziel ≤ 20 MiB |
| Saubere APT-Installation in Ubuntu 26.04 amd64 | bestanden; vollständiger Paketinhalt mit `dpkg -V` geprüft |
| System-GSettings ohne Quell-/Buildbaum | Schema gefunden; Theme über getrennte Prozesse geschrieben und gelesen |
| Icon und MIME-Zuordnung | Theme findet das Icon; sechs Markdown-Endungen erkannt; beide MIME-Typen führen Hashline als Handler |
| Desktop-Start | Kaltstart und Übergabe an laufende Instanz über GIO und installierten Desktop-Eintrag bestanden |
| CLI | Version und Hilfe ohne Display; relative Pfade aus anderem Arbeitsverzeichnis, führendes Minus, Leerzeichen, Unicode, `%` und `#` bestanden |
| Instanzübergabe | ein Prozess/ein Fenster; Mehrdatei-Hinweis und Aktivierung ohne Datei geprüft |
| AT-SPI im installierten Release | Dokumentrolle, Textschnittstelle und Unicode-Zeichenoffsets bestanden |
| Reinstallation und Entfernung | erneut konfigurieren, entfernen, wieder installieren und purgen; Schema aus dem gemeinsamen Cache entfernt |
| Bestehende Standardanwendung | registrierter anderer Reader und `mimeapps.list` bleiben unverändert |

Die Laufzeitprüfung verwendet Xvfb, AT-SPI, einen eigenen D-Bus und einen
echten dconf-Backend im Wegwerfcontainer. Die Ubuntu-Minimalimage-Regel, die
Dokumentation und Manpages ausschließt, ist dort deaktiviert, damit `dpkg -V`
auch diese Dateien prüft. Der Host erhält keine Hashline-Installation.
Software-Rendering unter Xvfb erzeugt DRI3-Hinweise; diese sind keine
Performance- oder Darstellungsfreigabe.

Reproduzierbare Befehle stehen unter [Installation](../installation.md).

Die Paketprüfung deckte einen Fehler im bisherigen automatischen
`GApplication`-Öffnen auf: ein erhalten gebliebener `--`-Optionsabschluss wurde
als Dateipfad geöffnet. Der CLI-Handler konsumiert diesen Abschluss jetzt
explizit und verwendet `create_file_for_arg`, damit das Verzeichnis des
jeweiligen Aufrufers auch bei Instanzübergabe erhalten bleibt.

## Freigabestatus

**M3-Auslieferungsfunktionen sind implementiert; die vollständige M3-/v1-Abnahme
ist nicht erteilt.** Die isolierte Paketprüfung deckt Installation und den
GIO-Startpfad eines Dateimanagers ab. Eine echte saubere Wayland-Desktop-Sitzung
mit Dateimanager-Bedienung, Drag-and-drop, Clipboard und Linköffnen bleibt eine
eigene Abnahme. Visueller Referenzvergleich und vollständige n=30-Performance-
Messreihen fehlen; bekannte Budgetüberschreitungen bleiben in
[limitations.md](../limitations.md) und dem
[Benchmarkbericht](../../benchmarks/results/native-2026-09-09/REPORT.md)
sichtbar.
Die Ziele aus SPEC.md werden nicht verändert.
